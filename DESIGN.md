## antislop

For UI, copy, people, mobile layout, or code comments work, read `antislop.md` (core) and then the skill for the task:

- UI / visual: `skills/antislop-ui/SKILL.md`
- Copy & text: `skills/antislop-copywriting/SKILL.md`
- People: `skills/antislop-human/SKILL.md`
- Mobile / responsive: `skills/antislop-layoutmobile/SKILL.md`
- Code comments: `skills/antislop-code/SKILL.md`

Before starting, ask the user when antislop applies: during the work, or after it is done.

## Design Read

Membaca ZENFLIX sebagai: Platform streaming B2C, diskon minimal, gaya UI yang elegan dan 'modern BUT friendly', dial ENERGY 2 / RHYTHM 2 / MOTION 2.

---

## Design Details

**Identity**: Modern, fresh streaming platform focused on high-quality film content.

**Personality**: Sleek, approachable, trusted, fast, streaming-first.

**Palette**: Neutral base (white, black, grey) with one bold accent color (teal or orange).

**Typography**: Modern sans-serif (Inter, Geist, or similar).

**Mood**: Bright, HD quality, easy film consumption.

**Dials**: ENERGY 2 / RHYTHM 2 / MOTION 2.
